# 🚀 我的项目页

这是**你自己的项目展示页**，网址是 https://cp2phi.github.io/kiwi-coder/my-project/ 。

想改它，就改这个文件夹里的 `index.md`：点进去 → 右上角 ✏️ 铅笔 → 按文件里 `<!-- 👉 -->` 注释的提示改字 → 绿色 **Commit changes**。等 1～2 分钟，刷新网页就能看到。

页面里的画板会自动读取你存在 `my-work/` 里的项目文件。读哪一个，由 `index.md` 最上面的 `project_file:` 那一行决定（默认是 `week11-project.py`，第 12 课改成 `week12-showcase.py`，只改文件名，不要加引号）。文字 app 可以把 `# project_canvas: no` 前面的 `# ` 删掉，就不显示画布。

改坏了？仓库的 Actions 出现红色 ❌ 的话：打开 `index.md` → 右上角 **History** → 找到上一个好的版本 → 复制回来再 Commit；或者请家长帮你 revert。
