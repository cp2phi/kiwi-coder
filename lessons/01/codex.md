# 🤖 Codex：会写代码的 AI 搭档

## 是什么？为什么用？

**Codex** 是一个 AI 编程助手。你用**说话的方式**（中文也行）告诉它想做什么，它帮你**写代码、解释代码、找 bug**。

<div class="flow">
  <div class="f"><span class="e">💭</span><b>你有个想法</b></div>
  <div class="arrow">→</div>
  <div class="f"><span class="e">⌨️</span><b>用文字告诉它</b></div>
  <div class="arrow">→</div>
  <div class="f"><span class="e">🤖</span><b>它写代码</b></div>
  <div class="arrow">→</div>
  <div class="f"><span class="e">🔍</span><b>你检查、运行</b></div>
</div>

<div class="box box-think"><b>🧑‍✈️ 你是队长，AI 是队员。</b>AI 很厉害，但<b>会犯错</b>，所以队长要检查。</div>

## 三条守则

<div class="box box-rule">
① <b>学习时要提示，不要答案</b>：「给我一个提示」比「直接帮我写」学到的多。<br>
② <b>AI 说的要检验</b>：代码运行了才算数。<br>
③ <b>不告诉 AI 隐私</b>：真名、地址、学校、密码都不说。
</div>

## 怎么用？

  <div class="mock-bar"><i></i><i></i><i></i><span class="mock-url">Codex</span></div>

    <div class="bubble me">用小学生能听懂的话，解释 turtle 里的 forward 是什么意思？</div>

    <div class="mock-row" style="margin-top:10px"><span class="dot">1</span><div class="mock-input" style="flex:1">告诉 Codex 你想做什么……</div><span class="mock-btn dark">发送</span></div>

<ul class="legend">
  <li><span class="dot">1</span><div>在<b>输入框</b>里写你想问的、想做的，发送。</div></li>
  <li><span class="dot">2</span><div>读 Codex 的回答。要代码的话，<b>复制</b>它，贴到我们的画板里运行。</div></li>
</ul>

<p class="muted">（Codex 有网页版、电脑 App 和 VS Code 插件，样子不太一样，但用法都是：写指令 → 看回答 → 检查。）</p>
