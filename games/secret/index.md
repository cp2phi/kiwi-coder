# 🔐 <span class="zh">密码破译</span><span class="en">Secret Code</span>

<p class="zh">每一关都藏着一个密码。你的任务：<b>改代码</b>，让程序打印出<b>一模一样</b>的密码（大小写、空格、换行都要一样）。运行后画板会把<b>你的输出</b>和<b>需要的输出</b>放在一起对比，看看差在哪里。关卡越往后，需要的魔法越多：变量 → 字符串 → 循环 → 列表 → 函数 → 字典。从第 7 关开始，密码<b>每次运行都会变</b>，所以光打印答案是过不了关的——你得写出真正的<b>破译程序</b>。</p>
<p class="en">Every level hides a secret. Your job: <b>change the code</b> so the program prints the secret <b>exactly</b> (capitals, spaces and line breaks all count). After you run it, the playground shows <b>your output</b> next to the <b>wanted output</b> so you can spot the difference. Later levels need more magic: variables → strings → loops → lists → functions → dictionaries. From level 7 on, the secret <b>changes every run</b>, so just printing the answer won't pass — you have to write a real <b>code-breaking program</b>.</p>

<details class="hint"><summary>💡 <span class="zh">提示 3</span><span class="en">Hint 3</span></summary><span class="zh">倒过来有两种办法：最后 <code>return result[::-1]</code>（第 3 关学过），或者一边拼一边接到前面：<code>result = text[i] + result</code>。</span><span class="en">Two ways to reverse: <code>return result[::-1]</code> at the end (you met it in level 3), or build it backwards as you go: <code>result = text[i] + result</code>.</span></details>
