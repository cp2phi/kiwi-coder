# 🛰️ <span class="zh">火星车</span><span class="en">Mars Rover</span>

<p class="zh">火星离地球太远了，无线电信号单程就要好几分钟到二十多分钟，所以火星车（比如美国的「毅力号」、中国的「祝融号」）很多时候要<b>自己看、自己决定</b>。这个游戏里也一样：<b>每次点运行，地图都会变</b>！你不能数格子、背路线，只能用<b>传感器</b>（<code>rock_ahead()</code> 前面有石头吗？<code>sample_here()</code> 脚下有样本吗？）写出一套<b>规则</b>，让火星车在任何地图上都能完成任务。</p>
<p class="en">Mars is so far away that a radio signal takes several minutes — up to more than twenty — to get there, so Mars rovers (like NASA's Perseverance and China's Zhurong) often have to <b>look and decide for themselves</b>. Same here: <b>the map changes every time you click Run</b>! You can't count cells or memorise a route — use the <b>sensors</b> (<code>rock_ahead()</code> is there a rock ahead? <code>sample_here()</code> is there a sample under me?) to write <b>rules</b> that complete the mission on any map.</p>
