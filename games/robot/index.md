# 💎 <span class="zh">宝石机器人</span><span class="en">Gem Robot</span>

<p class="zh">橙色的机器人站在格子世界里，脸朝右。<code>move()</code> 走一格，走到<b>蓝色宝石</b>上面用 <code>pick()</code> 捡起来（变成金色就是捡到了）。捡完<b>所有</b>宝石就过关！走出格子或撞到<b>灰色石头</b>会出现红点。关卡会越来越大——第 3–4 关要用循环，第 5–6 关<b>必须</b>先用 <code>def</code> 教机器人一招（第 7 课）。第 7–9 关的地图<b>每次运行都会变</b>，机器人要学会自己「看」！</p>
<p class="en">The orange robot lives in a grid world, facing right. <code>move()</code> goes one cell; stand on a <b>blue gem</b> and <code>pick()</code> it up (it turns gold). Collect <b>all</b> the gems to win! Leaving the grid or hitting a <b>grey rock</b> shows a red dot. Levels get bigger — levels 3–4 need loops, and levels 5–6 <b>require</b> teaching the robot a trick with <code>def</code> first (Lesson 7). In levels 7–9 the map <b>changes every run</b>, so the robot has to look for itself!</p>

<h2 id="sensors">🔭 <span class="zh">第 7–9 关：地图每次都会变！</span><span class="en">Levels 7–9: the map changes every run!</span></h2>
<p class="zh">从第 7 关开始，每次点运行，地图和宝石都<b>不一样</b>——数格子、背路线都没用了。机器人装上了传感器，你要写一个<b>任何地图都能用</b>的程序。乱 <code>pick()</code> 也不行：没有宝石的地方捡一次就不算过关。</p>
<p class="en">From level 7 on, the map and the gems are <b>different</b> every time you click Run — counting cells or memorising a route won't work. The robot now has sensors: write a program that works on <b>any</b> map. No random <code>pick()</code>s either: picking where there's no gem means no pass.</p>
